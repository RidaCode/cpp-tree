# Code of conduct

This project welcomes learners and contributors with different backgrounds and
levels of experience. These expectations apply to issues, pull requests, reviews,
and other spaces maintained for this project.

## Expected behavior

- Treat people with respect. Be patient with questions and differing experience.
- Give specific, constructive feedback about the work.
- Respect boundaries, privacy, and requests to stop an interaction.
- Accept corrections, take responsibility for mistakes, and help keep discussion useful.

Harassment, discriminatory abuse, sexual harassment, threats, deliberate
intimidation, and publishing another person's private information are not
acceptable. Repeated personal attacks or disruption may also lead to moderation.

## Reporting and moderation

Report a problematic GitHub comment with GitHub's **Report content** control. This
provides a route to GitHub and, where GitHub offers it, repository administrators;
it does not promise a private project-maintainer inbox. Do not post sensitive
personal details in a public issue. GitHub's abuse-reporting route remains
available if the concern involves a maintainer.

Maintainers may clarify expectations, edit or remove inappropriate content, lock a
thread, restrict participation, or block an account. The response should reflect
the severity and pattern of behavior. Serious threats or harassment may result in
immediate removal without a prior warning. Apply these expectations consistently,
including to maintainers.

When possible and appropriate, explain a moderation decision privately, limit
access to sensitive reports, and allow a good-faith response. No guaranteed
response time or round-the-clock moderation is promised.
